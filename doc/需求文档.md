# Microsoft Rewards 自动化工具 — 需求文档

> 版本：v1.0  
> 日期：2026-06-08  
> 技术栈：C# + Playwright for .NET / Selenium

---

## 一、项目概述

开发一款 **C# 桌面端自动化程序**，模拟人工操作自动完成 Microsoft Rewards 平台上的日常任务，最大化积分收益。程序需支持无人值守定时运行，并具备完善的日志与异常处理机制。

---

## 二、Rewards 平台核心模块分析

### 2.1 积分获取渠道

| 模块 | 说明 | 积分量级 | 自动化难度 |
|------|------|---------|-----------|
| **Bing PC 搜索** | 使用 Bing 进行桌面端搜索 | ~90-150 pts/天 | ⭐ |
| **Bing Mobile 搜索** | 模拟移动端搜索（需 UA 切换） | ~60-100 pts/天 | ⭐ |
| **Edge 浏览器奖励** | 使用 Edge 搜索额外加分 | ~20 pts/天 | ⭐ |
| **Daily Set（每日任务集）** | 含 Quiz、Poll、搜索类任务 | ~30-50 pts/天 | ⭐⭐ |
| **Punch Cards（打孔卡）** | 周期性多步骤大任务 | 50-100+ pts/次 | ⭐⭐⭐ |
| **日常任务** | 拼图、电影、日记等小任务 | 5-15 pts/个 | ⭐⭐ |
| **印章奖励** | 赚取 12 个印章获得 1,000 pts | 1,000 pts/周期 | ⭐⭐⭐ |
| **福利领取** | Star 奖励、每月升级、搜索奖励等 | 不定 | ⭐ |
| **积分手动领取** | 完成任务后需手动领取，有过期时间 | 不定 | ⭐ |
| **视觉搜索** | 使用 Bing 视觉搜索功能 | 不定 | ⭐⭐⭐ |
| **移动应用签到** | Bing App 每日签到 | ~5-50 pts/天 | ⭐⭐⭐ |
| **限时活动 / 特殊任务** | 节日/推广期活动 | 不定 | ⭐⭐⭐ |
| **Xbox/PC Game Pass 任务** | 游戏相关任务（可选） | 不定 | ⭐⭐⭐⭐ |

### 2.2 用户等级机制（实际页面：银牌/金牌体系）

> ⚠️ 文档初版基于公开资料写的 Level 1/Level 2，实际中国大陆 Rewards 页面显示为 **银牌 → 金牌** 体系，含进度条和升级要求。

| 等级 | 说明 | 升级条件 |
|------|------|---------|
| **银牌** | 初始等级 | — |
| **金牌** | 更高收益 | 需达到指定积分 + 完成指定活动数 |

- 首页显示进度条：`距离金牌会员的进度 • 还需积分: XXX • 还需完成活动: X`
- 不同等级对应不同的搜索积分上限和福利

### 2.3 连签任务体系（Streak）

实际页面包含多种连签任务，每种独立计算：

| 连签类型 | 周期 | 奖励 | 说明 |
|---------|------|------|------|
| **必应搜索连签** | 7天 | +3→*100 | 每日完成 Bing 搜索 |
| **每日连签活动** | 7天 | +30→*100 | 每日完成全部 3 项 Daily Set |
| **必应应用连签** | 7天 | +5→*50 | 每日 Bing App 签到 |
| **连续7天完成每日活动** | 7天 | 不定 | 额外的连签任务卡片 |
| **使用必应连续搜索7天** | 7天 | 不定 | 额外的连签任务卡片 |
| **连续签到必应应用7天** | 7天 | 不定 | 额外的连签任务卡片 |
| **默认搜索引擎14天** | 14天 | 不定 | 将必应设为默认搜索引擎 |

#### 传统 Streak 奖励（Daily Set 连续完成）

| 连续天数 | 额外奖励 |
|---------|---------|
| 3 天 | 45 pts |
| 8 天 | 75 pts |
| 13 天 | 105 pts |
| 20 天 | 120 pts |
| 27 天 | 135 pts |
| 34 天+ | 150 pts / 每10天 |

## 三、功能需求

### 3.1 核心自动化功能

#### FR-001：账户安全登录
- 支持 Microsoft 账号密码登录
- 支持 Two-Factor Authentication (2FA/TOTP) 处理
- 支持保持登录状态（Cookie/Session 持久化）
- 异常处理：验证码、账户锁定检测、登录失败重试

#### FR-002：Bing PC 搜索自动化
- 每日自动完成 PC 端 Bing 搜索任务（达到当日上限）
- 支持随机搜索词库（内置 500+ 常用搜索词）
- 每次搜索间隔随机化（3~8 秒），模拟真人行为
- 搜索结果页面停留随机时间
- 搜索词轮换避免重复

#### FR-003：Bing Mobile 搜索自动化
- 通过切换 User-Agent 模拟移动端搜索
- 逻辑同 PC 搜索，独立计数
- 支持移动端特有的搜索奖励

#### FR-004：Daily Set 自动完成
- 自动识别 Dashboard 上的 Daily Set 任务（每日 3 项）
- **Poll 任务**：自动选择任一选项提交
- **Quiz 任务**：
  - 检测题目类型（单选/多选/This or That）
  - 随机选择或尝试正确答题（支持答案库积累）
  - 连续答题，直到完成所有题目
- **搜索类任务**：自动执行指定搜索词（如"我附近即将举行的活动"）
- **点击类任务**：自动点击指定链接/按钮并返回
- 任务完成后验证积分是否到账
- **注意**：Daily Set 的 3 项任务可能有外部链接跳转，需处理跨页面返回

#### FR-004a：福利奖励自动领取
- 自动检测首页右侧福利区域的待领取奖励：
  - **默认搜索奖励**（如"上个月赚取的积分: 待领取"）
  - **每月升级奖励**
  - **必应 Star 奖励**
- 自动点击领取，避免积分过期

#### FR-004b：积分领取弹窗处理
- 完成任务后积分并非自动到账，需手动点击"领取积分"
- 自动检测"可领取"数字角标
- 打开领取弹窗，逐个领取待领取积分
- 处理积分过期提醒（显示"到期日期"）

#### FR-005：Punch Cards（任务）自动完成
- 扫描"任务"区域的大任务卡片（如：盗贼之海、查看仪表板等）
- 每个 Punch Card 含多个子任务（如 0/5、0/4）
- 按顺序完成每个 Punch Card 的步骤
- 处理多种交互类型（点击、观看、搜索、浏览）
- 完成后验证奖励到账

#### FR-005a：日常任务自动完成
- 扫描"日常任务"区域的小任务卡片
- 任务类型包括：
  - **拼图任务**：排列图块以显示图像（5 pts）
  - **电影/活动任务**：如"附近的电影之夜"（15 pts）
  - **日记任务**：如"日记解锁"（15 pts）
  - **搜索栏任务**：启用搜索栏并连续使用（100 pts）
  - **推广任务**：滴滴优惠券、邀请好友等
- 区分已完成和未完成任务，跳过已完成

#### FR-006：更多活动自动发现与完成
- 自动识别 Dashboard 上 "More activities" / "日常任务" 区域的额外任务
- 根据任务类型选择对应的处理策略
- 跳过无法自动化的任务（如需要实际购买、需要真实地理位置等）

#### FR-006a：视觉搜索任务
- 首页"视觉搜索"活动区域
- 需要使用 Bing 的视觉搜索功能
- 标记为"如何激活"的任务可能需要首次启用

#### FR-006b：移动应用签到
- 首页"移动应用"区域的签到任务（签到: 0/1）
- 需要模拟移动端环境或配合手机 App
- 有一定自动化难度，可选实现

#### FR-007：积分统计与报告
- 任务执行前后读取当前积分余额（首页右上角"可用积分"）
- 读取今日积分（积分赚取页面"今日积分"卡片）
- 读取每日连签天数
- 计算本次运行获得的积分
- 生成执行报告（时间、完成任务、获得积分、错误信息）

#### FR-007a：会员等级追踪
- 读取当前会员等级（银牌/金牌）
- 读取距离下一等级的进度（百分比、还需积分、还需活动数）
- 在报告中展示等级变化趋势

### 3.2 系统功能需求

#### FR-008：定时调度
- 支持 Windows 任务计划集成
- 内置定时器，可配置每日运行时间
- 支持立即执行与测试模式

#### FR-009：多账户支持（可选）
- 配置文件支持多个 Microsoft 账户
- 串行执行避免风控
- 账户隔离的 Cookie/Session 管理

#### FR-010：反检测与风控规避
- 随机操作间隔（点击、输入、页面切换）
- 浏览器指纹伪装（分辨率、时区、语言）
- 模拟鼠标移动轨迹（非瞬移）
- 避免每日完全相同的执行时间（±30分钟随机偏移）
- 搜索词自然化（时事热点词库定期更新）

#### FR-011：日志与监控
- 结构化日志（时间戳、级别、模块、消息）
- 日志文件按日期分割
- 支持日志级别配置（Debug/Info/Warning/Error）

#### FR-011a：异常邮件通知
- **触发条件**：任务执行异常、浏览器崩溃、账户异常、积分领取失败、连续多次任务失败
- **邮件内容**：异常类型、发生时间、错误堆栈、当前账户状态、已执行任务清单
- **SMTP 配置**：服务器地址、端口、发件人邮箱、收件人邮箱、授权码/密码、启用 SSL
- **防轰炸机制**：相同异常类型 30 分钟内只发送一次；失败重试 3 次
- **可选日报邮件**：每日执行完成后发送摘要（获得积分、完成任务、账户状态）

#### FR-012：配置管理
- 外部配置文件（appsettings.json）
- 可配置项：账户信息、定时设置、搜索数量、浏览器模式、日志级别等
- 配置热加载或重启生效

## 四、技术架构需求

### 4.1 推荐技术方案

| 组件 | 推荐方案 | 备选方案 | 说明 |
|------|---------|---------|------|
| 浏览器自动化 | **Playwright for .NET** | Selenium WebDriver | Playwright 速度更快、API 更现代，微软官方产品对微软站点兼容性更好 |
| 浏览器 | Chromium (Edge) | Chrome | Edge 与 Rewards 集成度最高 |
| 项目类型 | Console App + 可选 Windows Service | WPF GUI | 初期以 Console 为主，后续可扩展 GUI |
| 配置 | appsettings.json | 自定义 XML | 标准 .NET 配置模式 |
| 日志 | Serilog | NLog / 自定义 | 结构化日志，文件+控制台输出 |
| 定时任务 | Quartz.NET | Windows Task Scheduler | 内置定时更灵活 |
| 数据存储 | SQLite (轻量) | JSON 文件 | 保存搜索历史、答案库等 |

## 五、非功能性需求

### 5.1 性能需求
- 单次完整任务执行时间 ≤ 10 分钟
- 浏览器启动时间 ≤ 5 秒
- 内存占用 ≤ 300MB（单账户）

### 5.2 可靠性需求
- 任务失败时自动重试（最多 3 次）
- 单次任务失败不影响其他任务继续执行
- 程序崩溃后下次运行能正常恢复

### 5.3 安全需求
- 账户密码/TOTP 密钥加密存储（DPAPI 或 AES）
- 日志中脱敏敏感信息
- 不收集、不上传用户数据到第三方

### 5.4 合规与风险提示
- 明确标注：本工具仅供学习和个人使用
- 微软 ToS 风险告知：过度自动化可能导致账户限制或封禁
- 建议控制每日执行频率，避免极端模式

## 八、风险与应对

| 风险 | 影响 | 应对策略 |
|------|------|---------|
| 微软页面改版 | 高 | 模块化设计，元素定位集中管理，快速更新选择器 |
| 账户风控/封禁 | 高 | 模拟真人行为、控制频率、随机化、避免 24h 不间断运行 |
| 登录验证码/2FA | 中 | 支持 TOTP 自动计算；图形验证码需人工介入或打码平台 |
| 积分过期未领取 | 中 | 自动检测并领取待领取积分，设置过期提醒 |
